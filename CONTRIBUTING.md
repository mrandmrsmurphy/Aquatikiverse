# Contributing

Aquatikiverse is a personal learning project, so the fictional worlds and their identities are set by the author. Outside input is still welcome in these forms:

- **Science corrections.** If a calculation, constant, citation or explanation is wrong, open an issue naming the page, the claim and a source.
- **Typos and broken links.** Open an issue or a small pull request.
- **Questions and suggestions.** Open an issue. Ideas for new reference articles are especially useful.

Pull requests that rewrite a world's premise, rename things or add new lore are unlikely to be merged, but you are free to fork and adapt the material under the terms in [`LICENSE.md`](LICENSE.md).

If you edit pages, keep to the vault's conventions: Markdown with Obsidian `[[wikilinks]]`, numeric frontmatter in common units, and a clear line between calculated results and chosen speculation.
