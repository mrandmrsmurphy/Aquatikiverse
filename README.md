# Aquatikiverse

[![License: CC BY-NC-SA 4.0](https://img.shields.io/badge/License-CC%20BY--NC--SA%204.0-lightgrey.svg)](LICENSE.md)

A worldbuilding vault for practicing physics, chemistry and biology together. It holds fictional stars, planets, biospheres and civilizations, each built so the numbers work: mass, orbit, light, climate and chemistry are calculated, and the speculative parts are labeled as speculation.

It is a personal learning project, shared with students and anyone curious. It is written as an [Obsidian](https://obsidian.md) vault, so the pages are plain Markdown linked with `[[wikilinks]]`.

Other entry points: [`List of Planets.md`](List%20of%20Planets.md) (every planet and moon with its bulk and orbital properties), [`Reading paths.md`](Reading%20paths.md) (ordered tours) and [`Glossary.md`](Glossary.md) (units, symbols and conventions).

## How the vault is organized

- One folder per star system (for example `Sol System/`, `Trigeminal System/`), holding the system hub and its stars, worlds, biospheres and species.
- `Encyclopedia/` holds general science reference articles that the world pages build on.
- `Sol System/` is the real solar system, used as a yardstick for the fictional ones.
- `images/` holds the shared figures embedded in pages.
- World pages carry numeric properties in their frontmatter, in common units, so worlds can be compared directly. A **Physical basis** section at the end of a page states which values are calculated and which are chosen.
- `AIOS/` and `logs/` hold working notes, scripts and the session log for maintaining the vault. They are not part of the articles.

## Viewing it

Clone the repository and open the folder as a vault in Obsidian to get links, graph view and the Properties panel. The pages also read as ordinary Markdown on GitHub, though wikilinks and image embeds will not resolve there.
