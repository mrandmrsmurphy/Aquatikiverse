# Biospheres

Every native or transplanted biosphere in the Aquatikiverse, with the solvent it runs in and the energy-yielding chemistry it relies on. They differ in chemistry as well as in organisms: some biospheres use water, some ammonia–water mixtures, liquid sulfur dioxide or liquid halides, and a few have no bulk liquid at all. The method for building and testing a biosphere's reaction set is in [[Redox Chemistry]].
